# Retail Sales & Customer Analytics

## Project Overview
This project analyzes the Online Retail II dataset using SQL Server and Python. It explores sales trends, product performance, country-level sales, and customer segmentation.

## Business Objectives
- Analyze monthly sales revenue and growth.
- Identify top-performing products.
- Compare sales performance across countries.
- Segment customers using RFM analysis.
- Present findings through charts and visualizations.

## Dataset
**Source:** UCI Machine Learning Repository — Online Retail II

https://archive.ics.uci.edu/dataset/502/online+retail+ii

The dataset contains retail transaction records, including invoices, products, quantities, prices, dates, and customer information.

## Tools Used
- Microsoft SQL Server
- SQL
- Python
- Pandas
- Matplotlib
- CSV

## SQL Analysis
The project includes SQL scripts for:
- Data cleaning and preparation
- Handling cancellations and returns
- Monthly sales revenue and growth
- Product performance analysis
- Customer analysis and RFM segmentation
- Country-level sales analysis
- Creating reusable SQL views

## Python Visualizations
Python and Matplotlib were used to create five charts:
1. Monthly revenue
2. Monthly sales growth
3. Top-performing products
4. Country sales
5. Customer segments

## Project Structure
- `SQL Scripts/` — SQL analysis queries
- `CSV Exports/` — Exported analysis results
- `Matplotlib Visualization/` — Python script and charts

*Folder names may differ slightly depending on how the project files are organized.*

## Limitations
- The analysis depends on the quality of the original transaction data.
- Product costs are not available, so actual profit and profit margins cannot be calculated.
- The findings describe the available historical data and do not guarantee future performance.

## Conclusion
This project demonstrates practical skills in SQL data cleaning, analytical queries, customer segmentation, CSV exports, and Python data visualization.
